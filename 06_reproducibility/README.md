# Reproducibility

*Archival packaging documentation for the whole repository.*

- **`REPRODUCE.md`** — integrity verification, unit/instrument test re-run, and the scientific-replay policy.
- **`PROVENANCE.md`** — the full chronological chain from the broader research programme through this archival packaging, and the independence taxonomy used throughout.
- **`FILE-INVENTORY.csv`** — machine-readable inventory of every archived scientific artifact (path, original path where known, SHA-256, size, epistemic status, phase, canonical/duplicate, notes).
- **`CHECKS.md`** — the missing/ambiguous-artifact register: every item searched for and not found, with the search performed and the consequence, plus the privacy/hardware-identifier note.
- **`PACKAGING-PROVENANCE-INCIDENT.md`** — full investigation of a since-superseded local packaging error affecting three files' provenance labeling (never affecting the confirmatory execution itself).
- **`verification/`** — output logs from the validation gates and test-suite runs performed during final assembly.

See the root `README.md` for the overall repository map and epistemic chronology.
