# Observable-Relative Causal Aliasing

Reproducibility repository for the study:

**Observable-Relative Causal Aliasing**

Author: **Rúben Alexandre Brito**

## Repository status

This repository preserves the scientific and computational provenance of the study, including the preregistered confirmatory experiment and the subsequent post-confirmatory analyses.

The preregistered confirmatory result is **negative**.

- C1′: 199/200
- E1: 150/150
- E2: 49/50
- Confirmatory decision: `passa = false`

Post-confirmatory analyses characterize the mechanism and scope of the confirmatory failure. They do not alter, reinterpret, or retroactively validate the preregistered confirmatory result.

## Epistemic structure

The repository is organized to preserve the chronological and epistemic separation between:

1. preregistration and amendments;
2. frozen confirmatory instrument;
3. confirmatory execution and scoring;
4. post-confirmatory analyses;
5. formal post-confirmatory closure;
6. manuscript materials;
7. reproducibility documentation.
