# Preregistration and Amendments

This directory preserves the preregistration record governing the confirmatory experiment.

It contains the frozen preregistration protocol and all amendments that were adopted before or during the formally documented preregistration process.

These materials define the confirmatory hypotheses, operational targets, candidate criteria, thresholds, execution rules, and relevant procedural safeguards.

## Epistemic status

Materials in this directory are part of the preregistration provenance.

They must not be modified to incorporate knowledge obtained from the confirmatory results or from subsequent post-confirmatory analyses.

Post-confirmatory analyses are archived separately under `03_post_confirmatory/`.
